# Lumia Stream Tools 🎨

A community guide to getting the most out of the **free tier** of [Lumia Stream](https://lumiastream.com) — covering setup, overlays, tips, and ready-to-use custom features.

> **Who is this for?** Complete beginners to experienced streamers. Every guide is written step-by-step with no assumed knowledge.

## ⚡ Quick Start

1. Download Lumia Stream → [lumiastream.com](https://lumiastream.com)
2. Follow the setup guide for your OS → [Mac](docs/getting-started/setup-mac.md) | [Windows](docs/getting-started/setup-windows.md)
3. Connect your streaming platform (Twitch, YouTube, etc.)
4. Try your first overlay → [Creating Overlays](docs/overlays/creating-overlays.md)
5. Add a leaderboard overlay to OBS → [Leaderboards](docs/custom-features/leaderboards/README.md)
